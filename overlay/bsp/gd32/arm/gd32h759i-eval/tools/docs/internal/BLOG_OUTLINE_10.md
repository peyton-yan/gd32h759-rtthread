## 二、写作原则

- **结果前置**：开头就是动图 + 数字卡，不铺垫背景。
- **图谱化**：能用图就不写字，能用表就不贴代码。
- **每节一句结论**：加粗一句话，方便扫读。
- **不写排错过程**：坑不展开（最多在"可靠性"节用一句"实现了 N 处真实工程化处理，见源码注释"带过）。
- **给数据**：能上数字就上数字（点数、频率、抖动、请求数、连续运行时长）。

## 三、章节大纲（每节：看点 → 放什么图 → 怎么制作）

### §0 开场钩子（开场 3 秒定生死）

- **看点**：拖动上位机滑块 → 板上 LED 亮 + 曲线同步动。
- **放**：**1 张 3–5 秒 GIF**（拆成"拖动 → 板子/曲线响应"两个画面）。
- **做**：屏幕录制 + 手机拍板子，剪成画中画（ScreenToGif / ffmpeg）。

### §1 成果一览

- **看点**：一张图看完"这套东西能干什么"。
- **放**：**能力总览大图**（左：上位机截图拼图；右：数字卡片）
  - 72 个点位 / Modbus TCP / **100Hz 闭环** / 22 区间一次轮询 / 非cacheable DMA 64KB / 上位机 Rust+Tauri
- **做**：Canva / Figma 拼图；数字卡用手写风字体（Excalidraw 文字）。

### §2 系统架构

- **看点**：一张图讲清"设备三层 + 上位机三层"。
- **放**：
  1. **分层架构图**（设备：`mb_tcp → mb_core → 点表 → 外设`；上位机：`Svelte → Tauri命令 → Modbus客户端`）
  2. **一次轮询的数据流图**（22 个区间 → 请求 → 响应 → 界面）
- **做**：Excalidraw（手绘风、中文友好、导出 PNG/SVG）。

### §3 设备侧：点表（本篇最"工程"的一节）

- **看点**："加一个点 = 加一行"，且上位机界面**自动生成**。
- **放**：
  1. **左右对照图**：左 = 点表源（极短片段或表格），右 = 上位机同一区的面板 —— 一一对应；
  2. **点表分区"地图"**：彩色块 `0x00 系统 … 0x0D 闭环`（配色即分区，一眼记住）；
  3. **点表全表**（附录 A 链接 `POINTS_TABLE.md`）。
- **结论**：**点表是唯一事实来源，前后端自动对齐。**
- **做**：Excalidraw 画分区地图；对照图截图 + 箭头标注。

### §4 上位机：界面能力

- **看点**：像"组态软件"但不花钱、还更好看。
- **放**：**4 段 GIF**：
  1. 多序列实时趋势 + **「各序列独立缩放」**开关切换（一眼看出不同量程也能同屏）；
  2. **越限告警**：红色横幅弹出 + 行高亮；
  3. **CSV 导出** → Excel 打开画图；
  4. 翻页浏览各区面板（自动生成）。
- **做**：ScreenToGif/Peek 每段 5–10 秒；导出 CSV 用 Excel/matplotlib 出图。

### §5 闭环控制（"控得住"）

- **看点**：真正的控制——设定值→PID→DAC→负载→ADC→反馈。
- **放**：
  1. **收敛 GIF**：改设定值 → `设定值/反馈/输出` 三条线收敛，误差→0；
  2. **联锁 GIF**：旋电位器/拔线 → 反馈越限 → **联锁横幅** → 切安全输出 → 恢复；
  3. **性能数据图**：`LOOP_SCAN_US` 的 1000 点抖动曲线/直方图（证明 100Hz 真的稳）。
- **结论**：**从"看得见"到"控得住"——闭环 + 联锁 + 实时性指标。**
- **做**：GIF 录屏；抖动图由 CSV → matplotlib。

### §6 可靠性与实时性（"做扎实"）

- **看点**：为什么它能当"工控"用。
- **放**：
  1. **内存/MPU 分区图**：`0x24000000 DATA` / `0x24070000 DMARAM(非cacheable)` / `0x30000000 ENETRAM` / `0xC0000000 SDRAM`，标 Cache 属性；
  2. **稳定性证据**：连续运行 X 小时无异常的日志截图 + 关键指标卡（jitter、丢包=0）。
- **一句话**：**DMA 与非cacheable 区分离，是 M7 上长期稳定的前提。**
- **做**：分区图用色块 + 标签；日志截图高亮关键行。

### §7 开源与一键复现

- **看点**：读者能"5 分钟跑起来"。
- **放**：
  1. **仓库目录树图**（overlay/patch 结构，一眼看懂"没重复托管 RT-Thread"）；
  2. **一键运行终端 GIF**：`bootstrap.sh` → `scons` → 跑上位机；
  3. **仓库链接 + 二维码**。
- **做**：终端录 GIF（asciinema/ffmpeg）；二维码在线生成。

### §8 结语 + 预告

- **看点**：把"控了个啥"讲透，引出下一篇。
- **放**：
  1. **能力雷达图**（监视 / 远动 / 总线 / 闭环 / 实时 / 运动控制）——"我们做到的" vs "工业完整形态"；
  2. **电机 + 功放实拍照片**（第11篇钩子）。
- **一句话**：**"控"的本质是让被控量跟踪目标，并对扰动与故障正确反应；下一步——运动控制。**
